# Patrium Services LLC

Responsive static website with the latest hero image and roof + P logo.

## Preview
Open index.html or run `python -m http.server 8000`.

## Deploy to Vercel
Upload these files to the root of a GitHub repository, then import the repository in Vercel. Choose Other as the framework. Leave the build command empty and use the repository root as the output directory.

## GitHub Pages
In repository Settings > Pages, select Deploy from a branch, main, / (root).

## Notes
No installation or build is required. Fonts load from Google Fonts. Call and Facebook buttons link directly to the business. Hero imagery is illustrative.
